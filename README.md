# LinuxPrograms

Small C programs and POSIX/Linux systems-programming exercises, organized by course exercise.
This repository contains coursework completed as part of a course at a University of Applied Sciences.
The project was first committed to this repository on March 26, 2021. This is pre-AI coursework, written before I used AI tools.

## Contents

- **Exercise 01:** Command-line arguments and environment variables, a command-line calculator, and simple command launchers.
- **Exercise 02:** File I/O, reversing file contents, comparing files, and storing and summing integers in a file.
- **Exercise 03:** File identity and text searching, including searching multiple files and comparing directory entries.
- **Exercise 04:** Process creation and management with `fork`, waiting for child processes, and passing data through a temporary file or pipe.
- **Exercise 05:** Signal handling, including SIGINT/SIGTERM, parent-child SIGUSR1 communication, and SIGCHLD notifications.
- **Exercise 06:** Pipe-based communication, non-blocking input, and a multi-process pipeline that counts matching processes.
- **Exercise 07:** A linked stack that reverses file lines, plus shared-memory communication between parent and child processes.
- **Exercise 08:** Shared-memory writer/reader programs synchronized with semaphores, handling individual people, repeated entries, and batches of records.
- **Exercise 09:** POSIX threads for calculating square roots, factorials and sums, and averages of generated data.
- **Exercise 10:** Thread synchronization with mutexes, condition variables, and reader-writer locks.

Comments in the source code are in Finnish.
